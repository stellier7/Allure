# Allure media

Upload salon photos and videos here. After they land in this folder, they can be wired into the site from `config.js`.

## Upload on GitHub (phone or computer)

Open this link, drag files in, and commit:

**[Upload pictures and videos](https://github.com/stellier7/Allure/upload/main/media)**

If that page is empty, use the repo upload page and name files with a `media/` prefix (example: `media/hero.jpg`):

**[Upload to the Allure repo](https://github.com/stellier7/Allure/upload/main)**

## Suggested filenames

| File | Where it appears |
|------|------------------|
| `hero.jpg` or `hero.mp4` | Full-screen opening image or video |
| `visit.jpg` | Interior photo next to hours |
| `ritual-1.jpg` … `ritual-4.jpg` | Four experience cards |
| `gallery-1.jpg` … `gallery-6.jpg` | Photo grid |
| `gallery-1.mp4` | Optional video in the gallery |

Use any extra names you like (`nails-gel.jpg`, `blowout.mp4`). Keep the original quality, then we will point the site at the files you actually uploaded.

## Size limits

- **Photos:** JPG, PNG, or WebP. Aim for under 3 MB each.
- **Videos:** MP4 or WebM. GitHub warns above 50 MB and blocks files over 100 MB. Short clips (10–30 seconds) work best.
- If a video is too large for GitHub, send a Google Drive / Dropbox / Instagram link instead.
